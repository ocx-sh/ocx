and ble.sh v0.3.4, v0.4.0-devel3 and nightly 0.4.0-nightly+d81fd54, measured on Linux x86_64 and Windows 11 build 26100 on
2026-10-11. macOS and BSD behaviour is `unverified: read only`.

Owns code that writes shell text for another shell and code that edits another shell's startup files: the quoter per target, the
hostile corpus, the data channel, the never-emit list, rc and profile locations and idempotent edits, prompt, directory-change
and pre-exec hooks, undo, PATH edits, completion registration, generated launchers and the cmd.exe Batch arm. It binds EMIT code
and the INST and RC scripts that edit rc files. It does not bind CI steps, dev scripts or sourced libraries unless they generate
shell text for another shell. Not owned here: quoting inside a script for itself (`SH-EXP`), the sh floor and shebang rules
(`SH-DIAL`), installer flow and exit codes (`SH-INST`), zsh, fish, nushell and elvish source rules (`SH-ZSH`, `SH-FISH`, `SH-NU`,
`SH-ELV`), PowerShell encoding and syntax policy (`PS-ENC`, `PS-COMPAT`), gate wiring (`SH-GATE`) and the test-suite skip rule
(`SH-TEST`). SH-EMIT-32 is retired and never reused (SH-TEST-10 owns the absent-interpreter rule). `OUT`, `EMITTED` and
`EMIT_TESTS` below are variables the adopter sets: a pathspec for generated text kept visible to git, the file holding one
emitter's output, and the pathspec of the emitter's tests.

## Group 1: A Round Trip Decides

Check `RT`: for each of the 36 corpus lines (name, TAB, hex of the UTF-8 bytes) have the emitter quote the value for the target,
run the text in the real interpreter, print the hex of the resulting variable and compare. Pass is 35 of 35 equal and `nul`
refused. A mismatch or a `NOT-REJECTED` is the finding. The `shell-integration` skill ships `corpus.txt` and the per-target
harness. The cases are `squote dollar backtick backslash trailing_bs dbl_bs newline cr_crlf percent unicode lead_dash lead_dashes
empty inject dquote bang glob_tilde space_tab operators pwsh_special u2018 u2019 u201a u201b u201c u201d u201e curly_inject
curly_dq_inject curly_mixed nul nu_hash trail_sq esc_bell datelike big4k`. Cells `Q1` to `Q6` list sites in emitter source.
`Q2`, `Q3`, `Q4` and `Q5` are triage aids and a hit is a site to read, not a gate.

```sh
for t in git xargs grep tr; do command -v "$t" >/dev/null 2>&1 || echo "PREFLIGHT: $t missing"; done; git rev-parse --is-inside-work-tree >/dev/null 2>&1 || echo "PREFLIGHT: no usable git work tree" # vd-ok: xargs here is a tool name, not an invocation
# Q1: a POSIX quoting helper in emitter source, every hit must sit in an sh-family arm
git ls-files -z --cached --others --exclude-standard -- '*.rs' '*.go' '*.py' | xargs -0 -r grep -H -n -F -e 'shell_words::quote' -e 'shell_escape::unix::escape' -e 'shlex.quote' --
# Q2: a Rust value spliced by name into an export or set line
git ls-files -z --cached --others --exclude-standard -- '*.rs' | xargs -0 -r grep -H -n -E -e '(export|set -gx|setenv|\$env:)[^"]*\{(value|val|path|v|s|str)(:[?#]+)?\}' -e '= "\{(value|val|path|v|s|str)\}"' --
# Q3: the same in Go and Python
git ls-files -z --cached --others --exclude-standard -- '*.go' '*.py' | xargs -0 -r grep -H -n -E -e '(export |set -x -g|fish_add_path|\$env[.:]|set paths|setenv).*%[sv]' --
# Q4: apostrophe doubling in a file that never names U+2019
git ls-files -z --cached --others --exclude-standard -- '*.rs' '*.go' '*.py' | xargs -0 -r grep -l -F -e "replace('\\''" -e "\"'\", \"''\"" -- | tr '\n' '\0' | xargs -0 -r grep -L -e '2019' --
# Q5: an emitter test file with no curly-quote case
git ls-files -z --cached --others --exclude-standard -- "$EMIT_TESTS" | xargs -0 -r grep -L -e '2019' --
# Q6: an emitted empty PowerShell assignment
git ls-files -z --cached --others --exclude-standard -- '*.rs' '*.go' '*.py' | xargs -0 -r grep -H -n -F -e " = ''" --
```

## Group 2: ShellCheck, a Grep or a Parse Decides

ShellCheck cannot see a Rust, Go or Python string literal. Run the emitter, write its sh output to `EMITTED` (exported) and run
`S5`, `S6` or `S8`. `S1` to `S4` list sites in emitter source and templates, and a hit is a site to read. `S5` prints nothing on
clean text. `S6` needs PSScriptAnalyzer 1.25.0 and prints one line per finding. `S7` is `checks/emit-ascii.sh` (copy it to
`scripts/`): it prints `FILE:LINE` for each line holding a non-ASCII or control byte, allows tab and CR, and exits 79 when `OUT`
matches no file, because a gitignored build directory lists none and would read as clean. `S8` is `checks/dialect-interp-set.sh`
(also SH-DIAL-04) and needs docker.

```sh
for t in git xargs grep awk mktemp shellcheck pwsh; do command -v "$t" >/dev/null 2>&1 || echo "PREFLIGHT: $t missing"; done; git rev-parse --is-inside-work-tree >/dev/null 2>&1 || echo "PREFLIGHT: no usable git work tree" # vd-ok: xargs here is a tool name, not an invocation
# S1: a dollar-quote built into emitted code
git ls-files -z --cached --others --exclude-standard -- '*.rs' '*.go' '*.py' | xargs -0 -r grep -H -n -F -e "=\$'" -e "\"\$'" --
# S2: process substitution in a bootstrap or a completion recipe
git ls-files -z --cached --others --exclude-standard -- '*.rs' '*.go' '*.py' '*.txt' '*.j2' '*.tmpl' '*.sh' '*.bash' '*.md' | xargs -0 -r grep -H -n -F -e 'source <(' -e '. <(' --
# S3: an eval of a command substitution, each hit that gates startup needs the capture form
git ls-files -z --cached --others --exclude-standard -- '*.sh' '*.bash' | xargs -0 -r grep -H -n -F -e 'eval "$(' --
# S4: another shell's quoting facility used to quote for a target
git ls-files -z --cached --others --exclude-standard -- '*.rs' '*.go' '*.py' '*.sh' '*.bash' '*.tmpl' '*.j2' | xargs -0 -r grep -H -n -F -e '@Q' -e 'printf %q' -e '${(q)' --
# S5: emitted sh text, process substitution, dollar-quote and source under ShellCheck -s sh
shellcheck -s sh -f gcc -i SC3001,SC3003,SC3046 -- "$EMITTED"
# S6: emitted PowerShell against 5.1 syntax
pwsh -NoProfile -Command 'Invoke-ScriptAnalyzer -Path $env:EMITTED -Settings @{IncludeRules=@("PSUseCompatibleSyntax"); Rules=@{PSUseCompatibleSyntax=@{Enable=$true; TargetVersions=@("5.1")}}} | ForEach-Object { "S6: $($_.ScriptName):$($_.Line): $($_.Message)" }'
# S7: a non-ASCII or control byte in emitted or generated text, OUT names the pathspec
sh scripts/emit-ascii.sh "$OUT"
# S8: emitted sh under dash, busybox ash and bash 3.2 --posix
sh scripts/dialect-interp-set.sh "$EMITTED"
```

__x_hook() {
    local s=$?
    : hook body
    return "$s"
}
if [[ -n ${BLE_VERSION-} ]] && declare -F blehook >/dev/null 2>&1; then
    blehook PRECMD!=__x_hook
else
    __x_install_prompt_hook() {
        local cur pc=" ${PROMPT_COMMAND[*]-} "
        pc=${pc//;/ }
        pc=${pc//$'\n'/ }
        case $pc in *" __x_hook "*) return 0 ;; esac
        if [[ "$(declare -p PROMPT_COMMAND 2>/dev/null)" == "declare -a"* ]]; then
            cur=${PROMPT_COMMAND[0]-}
            PROMPT_COMMAND[0]="${cur:+${cur%"${cur##*[![:space:];]}"};}__x_hook"
        else
            cur=${PROMPT_COMMAND-}
            # shellcheck disable=SC2178 # bash before 5.1 has a string here
            PROMPT_COMMAND="${cur:+${cur%"${cur##*[![:space:];]}"};}__x_hook"
        fi
    }
    __x_install_prompt_hook
