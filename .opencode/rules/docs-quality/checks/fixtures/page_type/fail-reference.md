# Mirror flags

The tedious problem with mirroring is that we always forget which flag copies
signatures, so let's write down what we mean. This preamble runs on past the
cap that the rule sets for concept prose ahead of a reference page's own
content, because it keeps explaining the background instead of describing the
flags. A reference page describes what exists. It does not narrate how the
authors felt about building it, and it does not open by framing a problem the
reader is supposed to recognise. The words here exist only to push the count
past one hundred and fifty, which is the measured cap taken from thirteen real
how-to preambles whose median was seventy eight words. That is enough prose to
cross the line, and the rest of the page would carry the flag table a reader
actually came here to read in the first place, together with the error
conditions each flag can raise and the exit code it returns to the caller.
